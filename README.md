# Altrix Labs Health Copilot — Planning Pack

This pack contains the draft PRD, architecture, safety policy, development plan, evaluation plan, and starter Markdown knowledge/response templates.

## Read first
1. `PROJECT_CONTEXT.md`
2. `docs/PRD.md`
3. `docs/ARCHITECTURE.md`
4. `docs/AI_SAFETY.md`
5. `docs/DEVELOPMENT_PLAN.md`
6. `docs/EVALUATION.md`

## Important status
This is a planning/scaffolding pack, not a finished application. Medicine entries are templates, not a drug database. Candidate sources are not yet verified. Telugu strings are starter translations. Clinical review and legal review are required before any real-world deployment.

## Use with Antigravity
Open the repository in Antigravity and provide the implementation prompt in `ANTIGRAVITY_FIRST_TASK.md`. Ask it to inspect existing files before changing anything and to report findings first.
